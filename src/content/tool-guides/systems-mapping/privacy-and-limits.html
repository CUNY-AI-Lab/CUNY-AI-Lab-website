Your Memos and Map

The app saves both memos with the project. Submitting a memo or choosing Update map sends the active source and relevant map context through the Lab's model gateway. Follow your course's confidentiality rules and remove identifying material from fieldwork as required before submitting it.

Part 1 and Part 2 have separate text, drafts, and submitted versions. The app retains your manual nodes, connections, notes, and placement when you update a memo. Check the save status and use recovery downloads if an error appears.

Access and Sharing

Course instructors can see authorized roster and saved-progress information. To read a current map and its source material, they need an eligible project link or an exported copy you share. General-workspace projects remain separate from course projects.

A course project link requires current membership of that course. A general-workspace link requires Lab sign-in. Links expire after 90 days and can be revoked sooner. Check the contents of a file before sharing it, especially a JSON backup or Markdown export that includes both memos and notes.

Saved Work and Recovery

Up to 200 maps per workspace can be saved to your account. The app checks revisions before accepting a save and stores browser recovery copies. Someone using the same browser profile may be able to read those local copies. A deleted or conflicting copy can remain available through project recovery.

The Instructor Console may retain review submissions under its separate review workflow. Those records and progress counts do not establish that an instructor can open every current project.

Model and File Limits

A submission can return up to ten nodes. For the second memo, those ten cover both Exo settings and Macro conditions. The model creates no relationships in this workflow. A small or empty result can be appropriate when the source provides insufficient evidence.

Memo uploads must be no larger than 5 MB, and extracted text is also subject to request limits. Check imported PDF text. If a request is too large or fails, follow the displayed instructions and preserve the original source. A completed request still needs your judgment about the resulting labels, classification, and evidence.

Reports and Requests

Use the bug icon in the header to describe what went wrong or what could be better. The report includes verified account and release information while excluding memo text, map content, and Field Notes. If delivery fails, the form preserves your draft for retry. For access help, contact ailab@gc.cuny.edu.
