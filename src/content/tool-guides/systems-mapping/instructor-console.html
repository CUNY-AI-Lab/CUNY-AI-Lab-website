Opening the Console

Choose Instructor Console on Projects. Course settings holds questions and guidance. Saved progress shows course activity and revision records; Submissions is a separate queue for existing memo/suggestion reviews. Account holds sign-out, and Projects returns to the workspace.

Field Notes Prompts

In Course settings, choose Edit prompts to draft from the published version. Select a scale and write a question of up to 1,200 characters. Name the case or reading and connect the current map to the next inquiry.

Open Student preview to read the exact student-facing plain text, including unsaved edits. Editing and previewing make no model request. Choose Publish changes to save and publish, or Save draft to return later. Every scale needs a nonblank question; the editor finds missing ones. Changing a question preserves students' existing answers.

For the East Harlem case, ask whose presence the Micro map leaves out and which relationship students want to investigate at Meso. Their answer can guide the next observation.

Guidance and Materials

In Guidance and materials, choose a Part and mapping step. Part 1 covers Micro and Meso; Part 2 covers Exo and Macro. Each combination holds up to 2,500 characters of guidance and 4,000 characters of course material.

Preview saved guidance shows student-facing text without internal prompts. Preview level changes the preview's analytical context, not the saved configuration. Course guidance follows the app's fixed instructions, so level rules, student choice, privacy, and output structure still govern requests.

Versions

Course settings keep version history. Create draft copies a version for editing; name it and add an optional change note when saving. Publishing applies it to new model requests. To restore earlier settings, draft from that version and publish. Earlier records stay readable.

A save checks the revision. If your draft is stale, the app preserves it and offers Load server revision for comparison. If saving succeeds but publishing fails, the draft remains saved; retry publication.

Existing Review Submissions

Submissions holds separate memo/suggestion review records, including those retained from earlier workflows. Open an existing record, choose a feedback mode, write an annotation or focused question, and select Record feedback. Feedback leaves the student's map intact and does not block progress. Current Submit revision actions do not add full-work reviews here.

The queue refreshes every 30 seconds and pauses while you draft feedback. Its records are captured review material, not live views of current maps.

Students and Saved Progress

Open Students and saved progress to load the roster on demand. It shows enrolled students with a recorded visit, latest saved maps, level and stage, and submitted-revision counts. First map pending means no course map has been saved; check access or an unfinished start.

Students use Submit revision in the Notebook's review/Field Notes panel. It waits for saving and records deduplicated counts and timestamps. Request an eligible link or export to read the map, evidence, or Field Notes; revision records do not contain them.
