Items and Relationships

Select an item to edit Label in the Notebook, or select a connection to edit Relationship. Choose Save to apply the wording or Cancel to restore the saved text. Enter saves; Escape cancels. Moving focus or selecting another item does not save a draft. The same controls appear in suggestion Details.

Labels follow the item’s existing level. Meso relationships accept a verb or phrase; Exo relationships use the available decision-path choices. Invalid drafts leave the saved wording intact and show what needs revision. Saved wording updates any matching suggestion, and renaming an item updates its name in connected relationships.

An item’s level is fixed. To correct it, resolve dependencies, remove it, and add it at an appropriate level that creates items. Meso instead connects existing Micro items: choose Connect from [node name], select a different item, and describe the relationship and direction. Record evidence for items and connections, including frequency, duration, conditions, and change over time where applicable.

Drag items to arrange them; positions save with the project. Meso adds arrows to the Micro arrangement rather than a separate ring. Open Map tools → Map key for colors and line styles: Micro is teal, Meso amber, Exo plum, and Macro ink. Solid arrows show relationships; dotted lines mark scope and membership.

List View

When you want to inspect labels or find an incomplete relationship, open Map tools → List. The table shows each item's level and settings alongside relationships and their verbs. You can review the same map without navigating the canvas, including when you use a keyboard or screen reader.

Map Check

Use Map Check when you want another reading of an item or connection you have already mapped. Open its editing details and choose Check this item or Check this connection. The course model returns at most four short notes tied to map IDs. Choose a note to highlight its target on the canvas.

A check leaves the map unchanged and follows the course guidance and limits. Compare its notes with your evidence before revising. Return to the source when it questions a relationship, and keep unsupported suggestions for discussion.

Layout and Undo

Saving a label or relationship keeps node positions and the current view, although the text’s card may resize. Move an item using its updated label size, or choose Arrange map to lay out the map automatically. Use Ctrl/Cmd+Z to undo moves and arrangements from the current visit. Layout undo applies to positions, so evidence and label edits made afterward remain intact.

Choose Fit map to refit the view around every visible item, connection label, and relationship field. It fits the work on the map and leaves empty ring areas outside the view when needed.

Dependencies

The app blocks removal, or changing a Micro setting to a non-setting type, while active relationships, memberships, or scopes depend on it. Resolve the listed references first, then retry the change. Review the dependent work before removing its reference.
