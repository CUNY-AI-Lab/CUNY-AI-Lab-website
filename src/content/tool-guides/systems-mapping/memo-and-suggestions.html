Adding a Memo

Write a short question naming the person or group you want to understand. Then paste or upload the memo, which can contain field notes, a case description, an interview, or a reading. A model request has a size limit; if it is too large, shorten the memo before requesting guidance. The saved project remains unchanged when the request is rejected.

PDF uploads extract selectable text. Compare the imported text with the original and paste any missing passages. If no text can be read, paste the memo or upload a DOCX. The app also accepts DOCX, TXT, Markdown, HTML, and JSON memo files; uploads must be no larger than 5 MB.

Before the first request, read the transfer disclosure. It identifies the memo, inquiry, current level, and published course guidance sent with the request. Levels can use different memos. The next level's reading also receives earlier Field Notes as your own notes, separate from the source.

Reviewing Suggestions

Review each suggestion in the Notebook. Micro suggestions are items, while Meso suggestions are relationships between existing Micro items. Open Details to read the source passage and the model's reasoning. When a suggestion lacks a passage, examine it as an inference and check whether the memo supports it.

Choose Add to map to keep a suggestion, Set aside to retain it, or Remove to reject it. Finish review becomes available after every suggestion has a decision. For an optional later reading, use Update suggestions → Reread memo; the control shows Updating…. Saving edits alone does not request a reading.

Under Project → Preferences, you can turn on Automatic suggestion addition. The app then adds eligible suggestions to the map, where you can review and remove them. The setting is off by default.

What the Model Sends Back

The model may suggest fewer items or connections than the limits below, or none at all. It can also offer up to three pieces of guidance.

LevelMaximum suggestions per review
Micro10 items; no relationships.
Meso8 relationships between existing Micro items; no new items.
Exo6 items and 5 relationships.
Macro6 items and 12 links to earlier items; no relationships.

The app checks quotations against the memo and accepts differences such as straight and curly quotation marks. You should still read each passage and decide whether it supports the suggestion.

If guidance fails, read the message and follow its instructions. The app may retry some requests. If it asks you to reopen the map, check whether the guidance is ready before starting another request.

Guidance and Evidence

Guidance and evidence shows the instructor's published material for the current Part and stage. Requests include it, so the model receives course terms alongside the app's fixed rules.

Initial Guidance and Later Manual Work

An empty map needs a response from Generate guidance before you can begin building, even if the response includes no suggestions. If it fails, use Try again. A new level without work needs its own reading once course guidance is ready. Afterward, you can add and revise items yourself. Existing saved work remains available without another reading.
