Source Passages

You can select a node or connection on the map to open its details. An exact source passage appears under Quote from memo, with matching node names emphasized. Questions and other evidence appear under Evidence or question. Compare the passage with the relevant memo and decide what it supports.

The first and second memos stay separate. When a node refers to the second memo, return to Memo and select Part 2 to read its context. Source quotations and your interpretation serve different purposes, so use the interpretation field to explain the connection you are making.

Interpretation

For a node, Interpretation asks “Where does this connect? What is still uncertain?” For a relationship, it asks what the relationship explains and what is still uncertain. Refer to the memo or other course evidence, then choose Save note and check the status beside it.

If a model-generated node has the wrong label or classification, correct the node itself. You can explain what you infer from a source in the interpretation field, while keeping the original passage under Quote from memo.

Optional Field Notes

In Notebook, you can open Field notes (optional) to respond to the question for the current step. Your instructor can publish a question for each level. You can use the space to record an uncertainty, missing perspective, or question to investigate next.

Choose Save note and check the save status. Notes remain attached to their levels, and Previous notes lets you read earlier answers. You can continue through the map without writing Field Notes.

Sharing

Use a project link or exported copy when someone needs to read your work. A JSON project file includes both memos and saved notes, so review its contents before sharing it. Saving to your account records your own work and its progress.
