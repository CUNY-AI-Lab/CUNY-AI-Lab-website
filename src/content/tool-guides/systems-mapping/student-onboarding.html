Before Class

Before class, send the Lab course invitation and publish your Field Notes questions and Part 1 guidance in the Instructor Console. Post the memo, a link to the app, and this documentation where students can find them.

Open the First Memo Together

Ask students to sign in with CUNY Login, open Account, choose the course under Classes and materials, create a project named after the case, and paste the memo. Read the transfer disclosure together before anyone requests guidance.

Choose Generate guidance, and the button changes to Reading memo… while the app works. When suggestions appear, you might discuss the first few together. Open Details, compare each suggestion with its passage, and talk through whether to add it, set it aside, or remove it. Each student then makes a decision. If the review returns no suggestions, students can still continue and add Micro items supported by the memo.

Finish and Share the First Map

Use Memo to Map to finish the review and write Micro Field Notes, then try Sort the Suggestions to compare decisions. The model works from the text it receives, so students should return to their sources when they review its suggestions.

Ask students to save their work and choose Submit revision in the Notebook's Field Notes section. Check Saved progress to see their progress and revision counts. Submit revision does not send the map, so ask for a project link or an exported copy when you need to read it.

Explain What You Can See

You can see whether a course map exists, where the student is in the process, and how many revisions they have submitted. To read the map, students need to share a project link or an exported copy. The instructor role does not grant access to maps in the general workspace, which follow their own sharing rules.

When a Student Gets Stuck

If the course is missing, check that the student accepted the invitation and used the CUNY identity tied to it. Compare that identity with the roster. If a map is missing or No saved maps yet. appears, check both course and general workspaces. Maps stay where students created them, and a divergent browser copy remains available for recovery export.

If guidance fails, read the message and follow its instructions before choosing Try again. If the app asks you to reopen the map, check whether guidance is ready. To read the memo again later, use Update suggestions → Reread memo.

If Meso will not open, check for unanswered Micro Field Notes or an undecided suggestion. Once course guidance is ready, the app reads the memo once for each new level without work, and existing saved work opens without another reading.

For other problems, choose Report a problem and describe the action and result. The report includes the verified account name, the page, and the app release, and excludes memo text, map content, and Field Notes.
