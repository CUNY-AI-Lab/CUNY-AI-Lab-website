Prepare the Two Memos

Send the Lab course invitation and a link to Systems Mapping. Choose a first memo about local people, settings, and resources, and a second memo about outside institutions and broader conditions connected to the same issue. Share the sources and your assignment instructions before class.

Start a Project

Ask students to sign in, choose the course in Account, and enter a project title and creator name. Open the canvas, then use Memo to upload or paste the first source. Check the imported text before choosing Submit memo and add nodes.

Read one of the added nodes together. Compare its quotation with the memo and discuss whether the label and classification fit. Students can edit or remove nodes and add supported items themselves.

Draw a Relationship

Continue to Meso and demonstrate Connect from. Select the destination, name the relationship, and choose its direction. Ask students to explain the evidence for the wording they choose. All relationships are created by students.

Extend the Map

At Exo, open Part 2 in Memo and add the second source. Check that this is the intended second memo before submitting it. The original map remains visible as Exo settings and Macro conditions are added. Show how an outside setting or condition can affect a local relationship.

Field Notes are optional in the app. If your assignment uses them, explain the questions and what students should record. Set a clear point for sharing a project link or exported copy when you need to read the map.

Common Problems

If a course is missing, check the invitation and the CUNY account used to accept it. If a map is missing, check both course and general workspaces. Each map stays in the workspace where it was created.

If Continue is unavailable, check the current memo's submission status. A saved draft may still need Update map. A successful submission with no nodes still permits progression. Follow the displayed instructions after a failed request and use recovery options when a save fails.
