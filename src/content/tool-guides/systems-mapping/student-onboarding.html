Before Class

Before class, send the Lab course invitation and publish your Field Notes questions and Part 1 guidance in the Instructor Console. Post the memo, a link to the app, and these guides where students can find them.

Open the First Memo Together

Ask students to sign in with CUNY Login, choose the course under Your courses, create a project named after the case, and paste the memo. Read the transfer disclosure together before anyone requests guidance.

Choose Generate guidance; the control changes to Reading memo…. Discuss up to the first three returned suggestions. Open Details, compare each suggestion with its passage, and explain the choice to add, set aside, or remove it. Ask each student to make a decision. If a valid review returns no suggestions, students can continue and add supported Micro items themselves.

Finish and Share the First Map

Use Memo to Map to finish the review and write Micro Field Notes, then try Sort the Suggestions to compare decisions. The model works from the text it receives, so students should return to their sources when they review its suggestions.

Ask students to record a saved revision from the Notebook's review/Field Notes panel. Check Students and saved progress for progress and revision counts. If you need to read their maps, also request an eligible project link or an exported copy.

Explain What You Can See

You can see whether a course map exists, where the student is in the process, and how many revisions they have submitted. To read the map, students need to share an eligible link or export it for you. The instructor role does not give you access to maps in the general workspace; those maps follow their own sharing rules.

When a Student Gets Stuck

If the course is missing, check that the student accepted the invitation and used the CUNY identity tied to it. Compare that identity with the roster. If a map is missing or first map pending appears, check both course and general workspaces. Maps stay where students created them; a divergent browser copy remains available for recovery export.

If guidance fails, read the message before choosing Try again. If the app asks you to reopen the map, check whether guidance is ready. To read the memo again later, use Update suggestions → Reread memo.

If Meso will not open, check for unanswered Micro Field Notes or an undecided suggestion. A new level without work needs its own reading once course guidance is ready. Existing saved work remains available without regeneration.

For other problems, choose Report a problem and describe the action and result. Reports identify the verified account but exclude map content.
