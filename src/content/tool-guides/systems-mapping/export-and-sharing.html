Download Your Map

In Project → Export & share, you can choose PNG image or PDF to download the map. The choices open immediately. Download the map and decide who to share it with.

The image shows the nested Microsystem, Exosystem, and Macrosystem regions, the nodes, and your connections. Meso relationships appear within the local region. Node colors and system line patterns are included. The PDF contains an image of the map.

Project Backups

You can choose JSON for a project file with both memos, map layout, evidence, notes, and saved edit history. Import JSON reopens a compatible project file after checking it. The file includes your source material, so review it before sharing it.

Markdown gives you a text version, including the memos. CSV gives you map data for a spreadsheet, including relationship-group identifiers. Downloads are prepared in your browser.

Finish and Return

At Macro, Finish map opens a summary with Download PNG, Download PDF, Private backup, and More options. Return to map lets you continue working on the same project.

Share a Project Link

In Export & share, you can choose Project link to create or manage a saved link. Course links require current membership of that course, and general-workspace links require Lab sign-in. Links expire after 90 days and can be revoked sooner. A link shows the saved map as it changes.

Recovery

The Projects page provides notes and export options beside saved maps. Deleting a project leaves a recovery copy on that device. Project recovery lets you restore or download it. Revoke an existing project link separately when you want to stop sharing it.

If an older import, another browser tab, or an interrupted save conflicts with newer work, the app preserves a separate recovery copy. Read the save message and download recovery when offered. The recovery file includes the memos, evidence, and notes.
