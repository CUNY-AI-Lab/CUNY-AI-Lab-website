Picture and Document Exports

Choose PNG or PDF to download a picture of your map.

Choose Markdown if you want a text version of the map, or CSV if you want to work with the data in a spreadsheet. The CSV export changes cells that a spreadsheet might otherwise read as formulas.

Choose JSON when you need a project file you can reopen with its layout. The app checks the file before replacing the open project. Exports include work across the map's levels and exclude rejected or retired relationships and relationships with missing items.

Project Link

To share a live map, open Project → Export & share → Project link to create a link that is difficult to guess. Anyone opening the link must also have the right access. Course links work for current members of that course, while general-workspace links work for signed-in Lab members.

Project links expire after 90 days, though you can revoke one sooner. The link opens the live map, so anyone with access will also see changes you make after sharing it.

Submitting a Revision (Course Workspaces)

Save your work, then open the Notebook's review and Field Notes panel and choose Submit revision. The app records your progress after saving. It does not send the map itself.

Your instructor can see how many revisions you have submitted and when, but will need a project link or an exported copy to read the map. Saving your work does not submit a revision for you.

Projects and Private Backups

On the Projects page, choose Notes or Export beside a saved project to open its notes and export options. A private backup includes the full memo, Field Notes, and evidence.

Deleting a project leaves a private recovery copy on the device, but it does not revoke existing shared links. If you want to stop sharing, revoke the links before deleting the project. Use Project recovery on the Projects page to restore or download a deleted copy.

Recovery Copies

The app checks revisions before saving to your account so an older copy cannot silently overwrite newer work. The browser also keeps a recovery copy. If two tabs or a lost connection leave that copy out of step with the account, the app preserves it separately for recovery export. When an older copy of a project is imported over newer local work, the newer copy is also kept separately. If browser storage fails, you can download the project still open in your browser as a private recovery file. That file includes the full memo, Field Notes, and evidence.
