Project Link

To share a live map, open Project → Export & share → Project link to create an unguessable link. Anyone opening the link must also have the right access. Course links work for current members of that course, while general-workspace links work for signed-in Lab members.

Project links expire after 90 days, though you can revoke one sooner. The link opens the live map, so anyone with access will also see changes you make after sharing it.

Picture and Document Exports

Choose PNG or PDF for a picture of the map. Both place Micro items and Meso relationships in a shared area, with Exo and Macro columns when present. Legacy Meso nodes appear in explanatory text rather than as positioned cards. A numbered legend covers relationships, scope connections, and setting memberships. The PDF contains one raster page.

Choose Markdown if you want a text version of the map, or CSV if you want to work with the data in a spreadsheet. The CSV export neutralizes cells that could be interpreted as formulas.

Choose JSON when you need a project file you can reopen with its layout. The app checks the file before replacing the open project. Exports include work across the map's levels and exclude rejected or retired relationships and relationships with missing items.

The browser creates exported files locally. Use Prepare copy for to select the intended audience. Portable copies apply that audience's redactions and record which redactions occurred. Review the copy before sharing it.

Submitting a Revision (Course Workspaces)

Save your work, then open the Notebook's review and Field Notes panel and choose Submit revision. The app records your progress after saving. It does not send the map itself.

Your instructor can see how many revisions you have submitted and when, but will need a project link or an exported copy to read the map. Saving your work does not submit a revision for you.

Recovery Copies

The app checks revisions before saving to your account so an older copy cannot silently overwrite newer work. The browser also keeps a recovery copy. If two tabs or a lost connection leave that copy out of step with the account, the app preserves it separately for recovery export. When an older copy of a project is imported over newer local work, the newer copy is also kept separately. If browser storage fails, you can download the project still open in your browser as a private recovery file. That file includes the full memo, Field Notes, and evidence; keep it private and use the audience options in Export & share for copies intended for others.
