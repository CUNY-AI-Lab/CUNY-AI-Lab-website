Download Your Map

Open Project and choose Export & share. Under File format, choose PNG for an image, PDF for printing, or SVG if you want to zoom in on a large map. Choose Download, then share the file with anyone you choose.

All three formats keep the node positions, colors, and relationship labels you see on the canvas.

Project Backups

Choose Private project backup (JSON) to save a copy you can reopen with Import JSON. The backup includes your memos, map, evidence, notes, and edit history. You can also download your memos and notes as Markdown or your map data as a CSV file for a spreadsheet.

On the Projects page, choose Export beside your saved map. If your account and device have different copies, choose the one you want under Saved copy before selecting the file format and downloading it.

Finish and Return

At Macro, choose Finish map to see a summary. Under Download your map, choose a format and select Download. You can choose Return to map to continue editing.

Share a Project Link

In Export & share, you can choose Project link to create or manage a saved link. Course links require current membership of that course, and general-workspace links require Lab sign-in. Links expire after 90 days and can be revoked sooner. A link shows the saved map as it changes.

Recovery

The Projects page provides notes and export options beside saved maps. Deleting a project leaves a recovery copy on that device. Project recovery lets you restore or download it. Revoke an existing project link separately when you want to stop sharing it.

If an older import, another browser tab, or an interrupted save conflicts with newer work, the app preserves a separate recovery copy. Read the save message and download recovery when offered. The recovery file includes the memos, evidence, and notes.
