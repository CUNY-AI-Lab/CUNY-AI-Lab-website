Add and Revisit a Note

Move the playhead to the passage and press + Note in the transport row. You can pause first or add a note during playback. Type your comment and save; it appears beneath the stems with your name and the timestamp. Click a timestamp to return to that passage, or use [ and ] for the previous or next note.

Check Who Has Access

Notes on work assigned to Personal stay private to your account. Your instructor can also see notes on work assigned to a course. Current class members can read notes in a folder shared with the class. To let them add notes, an instructor chooses Class: listen and add notes and presses Save sharing. The course acknowledgment covers instructor review; the folder permission controls class access.

Course notes show the author's CUNY Login-verified name, and only that author can edit or delete them. A note added by Listening Guy records the requesting student's account as its initiator.

Keep Shared Notes Current

Notes on an open shared recording refresh every few seconds without disturbing playback or your draft. Use Refresh class notes for an immediate reload. If a connection problem prevents saving, your draft stays in the box for another attempt.

Write About What You Hear

A note can mark a moment you want to return to or describe something you hear, such as a bass line dropping out. You can also use notes to mark where you hear a verse, chorus, bridge, or solo begin.

In a shared folder, classmates can return to the same passage and read your notes. Listening Guy can also read the notes when it answers questions about the recording.
