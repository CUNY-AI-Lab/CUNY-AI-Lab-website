Add and Revisit a Note

Move to the passage and choose + Note beside the playback controls. You can pause first or add a note during playback. Type your comment and save, and it appears beneath the stems with your name and the timestamp. Click a timestamp to return to that passage, or use [ and ] for the previous or next note.

Check Who Has Access

Notes on work assigned to Personal stay private to your account. Your instructor can also see notes on work assigned to a course. Current class members can read notes in a class folder. So they can add notes, an instructor chooses Class: listen and add notes, then chooses Save sharing. The course acknowledgment covers instructor review, and the folder permission controls class access.

Course notes show the author's CUNY Login-verified name, and only the author can edit or delete them. A note added by Listening Guy is linked to the account of the student who requested it.

Refresh Shared Notes

Notes on an open shared recording refresh every few seconds without disturbing playback or your draft. Use Refresh class notes for an immediate reload. If a connection problem prevents saving, your draft stays in the box for another attempt.

What to Put in a Note

A note can mark a moment you want to return to or describe a change in the recording, such as a bass line dropping out. You can also use notes to mark the start of a verse, chorus, bridge, or solo.

In a class folder, classmates can return to the same passage and read your notes. Listening Guy can also read the notes when it answers questions about the recording.
