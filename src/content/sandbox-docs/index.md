## About the Sandbox

The CAIL Sandbox is a shared chat platform hosted and maintained by the [CUNY AI Lab](https://ailab.gc.cuny.edu) at the Graduate Center. It runs [Open WebUI](https://openwebui.com), configured for academic use at CUNY.

These guides and tool walkthroughs were developed as part of the tinkering track of the Critical AI Literacy Institute, from spring 2026 through fall 2026. They follow the work of trying a chat, checking its response, and preparing a course configuration for others to use.

## Start with a Chat

Follow [Getting Started](getting-started.md) to request access or join through a course invitation, then sign in and send a message. [Sandbox Basics](sandbox-basics.md) helps you read and question the response. If you need to locate a control, open the [Quick Tour](quick-tour.md); use [Basic Concepts](basic-concepts.md) when you need a term explained.

## Build and Test, If You Have Access

You can use shared resources without creating your own. Building configurations requires separate **Workspace** access; request it from the [CUNY AI Lab team](mailto:ailab@gc.cuny.edu).

With that access, create a [custom model](models.md), give it a focused [system prompt](system-prompts.md), and attach [course materials](knowledge-bases.md) when the task calls for them. Add [tools or skills](tools-skills.md) only when you need their capabilities. Test the result against your materials before using [Roles & Permissions](roles-permissions.md) to share it with the intended group.

## Prepare for Class

Start with an instructor's documented design in [Use Cases](use-cases.md), then consider the proposed adaptations in [Sample Activities](sample-activities.md). [Teaching Tips](teaching-tips.md) walks through preparing and reviewing an assignment; [Student Onboarding](student-onboarding.md) covers access, expectations, and the first shared activity.

## Get Help

Check the Sandbox's model selector for available chat models. The [Model Registry](https://ailab.gc.cuny.edu/models/) describes Model API offerings, which may differ from that selector. Contact [ailab@gc.cuny.edu](mailto:ailab@gc.cuny.edu) for access or configuration help, or visit the [Lab website](https://ailab.gc.cuny.edu) for workshops and office hours.
